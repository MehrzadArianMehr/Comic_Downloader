# BatCave

Desktop comic downloader for batcave.biz. Paste a comic link, pick chapters and get CBZ and PDF files.

## Features

- Floating, frameless window on macOS
- Chapter grid that fills cell by cell as a download progresses
- CBZ and PDF output, saved to `~/Downloads/BatCave Comics`
- Optional auto-send of PDFs to Apple Books via iCloud (macOS)
- Live battery indicator and a library of downloaded files

## Download

Get the latest version from [Releases](../../releases/latest):

| System | File |
|---|---|
| macOS (Apple Silicon) | `BatCave-macOS-AppleSilicon.dmg` |
| macOS (Intel) | `BatCave-macOS-Intel.dmg` |
| Windows 10/11 | `BatCave-Windows-x64.exe` |
| Linux | `BatCave-Linux-x64` |

**First launch**
- macOS: open the DMG, drag BatCave to Applications, then right-click it > Open.
- Windows: if SmartScreen appears, click More info > Run anyway. Uses Microsoft Edge (or Chrome) for its window.
- Linux: `chmod +x BatCave-Linux-x64 && ./BatCave-Linux-x64`. Needs Chrome or Chromium.
